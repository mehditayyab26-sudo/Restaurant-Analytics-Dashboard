# 🍽️ Restaurant Analytics Dashboard

An interactive **Restaurant Analytics Dashboard built in Microsoft Excel** to analyze sales performance, profitability, customer behavior, and restaurant operations through dynamic KPIs, charts, and slicers.

## 📊 Project Overview

This project transforms restaurant sales data into an interactive and easy-to-understand dashboard. It provides a clear overview of business performance and allows users to explore different aspects of the data using interactive slicers.

## ✨ Key Features

- Total Sales KPI
- Total Orders KPI
- Total Profit KPI
- Total Customers KPI
- Average Order Value
- Average Rating
- Monthly Sales Trend
- Monthly Profit Trend
- City-wise Sales Analysis
- Sales by Category
- Top 5 Best-Selling Menu Items
- Top Waiters by Sales
- Payment Method Distribution
- Dining Type Distribution
- Customer Type Analysis
- Average Rating by Category
- Interactive City, Dining Type & Month Slicers

## 🛠️ Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Analysis
- Dashboard Design

## 🎯 Project Objective

The main objective of this project is to practice **data analysis and dashboard development in Excel** by converting restaurant sales data into meaningful business insights through interactive visualizations.
